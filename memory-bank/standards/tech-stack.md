# Standard: Tech Stack

## Overview
Core technology decisions for this project.

## Decisions

### Languages
- **TypeScript**: Primary language for application and tests.

### Framework
- **Angular**: Latest version, for the frontend application.

### Testing
- **End-to-End**: Cypress with Cucumber (Badeball preprocessor).
- **Unit/Component**: Vitest.

### Tooling
- **Package Manager**: npm (default) or user choice.
- **Linting**: ESLint.
- **Formatting**: Prettier.
